### **1. Adaptive Thinking 機制爭議**
- **功能混淆與效能問題**：使用者（如 simonw、JamesSwift）指出新版的「Adaptive Thinking」機制與舊版的「Thinking Budget/Effort」模式不兼容，導致開發者需額外調整參數（如加入 `display: summarized` 才能顯示推理摘要）。部分用戶反映此功能反而降低模型表現，且 Anthropic 對回報的 bug 未積極處理。
- **效能回歸**：有開發者表示需「禁用 Adaptive Thinking + 提高努力參數」才能恢復基準表現，但 Anthropic 內部評估結果與用戶實際體驗存在落差。

### **2. Token 化與工具討論**
- **Tokenizer 更新影響**：Opus 4.7 的 tokenizer 改進文本處理，但相同輸入可能增加 1.0–1.35 倍 token 數量，引發對成本的擔憂。
- **第三方工具推薦**：
  - **Caveman**：用於簡化輸入文本以減少 token 使用，但被批評為「玩笑專案」，實際效果有限。
  - **Headroom**：更受推薦的 token 優化工具（提供桌面與 CLI 版本）。
  - **Claude Code 的隱晦參數**：需使用 `--thinking-display summarized` 才能恢復推理摘要顯示。
