**WebUSB 的優點與支持者觀點：**

3.  **開拓新可能性：** WebUSB 讓許多原本只能在特定作業系統（如 Windows）上運行的軟體，現在能在任何支援 WebUSB 的瀏覽器上運行。它也使得從瀏覽器直接刷寫手機韌體（如 GrapheneOS、Android）或配置物聯網裝置（如小米溫濕度計）成為可能，大大簡化了操作流程。
4.  **Mozilla 應原生支援：** 一些留言者批評 Mozilla 拒絕原生實作 WebUSB 的態度是不合理且不理性的，認為這項 API 具有巨大的實用價值。

**WebUSB 的擔憂與反對者觀點：**

1.  **供應商鎖定與長期可用性：** 這是最主要的擔憂。許多留言者擔心硬體供應商可能會過度依賴線上 Web 應用程式來提供更新和配置。一旦這些應用程式下線或不再維護，使用者可能會面臨裝置無法使用的風險，特別是對於昂貴且使用壽命長的裝置（如相機、樂器、音訊介面等）。

3.  **作為擴充功能的合理性：** 相對於原生實作，部分留言者認為 WebUSB 是一個非常小眾的用例，作為一個可選的擴充功能是更理想的解決方案。這樣可以減少瀏覽器的預設負擔、潛在的攻擊面和不必要的「膨脹」，讓使用者根據需求自行選擇是否啟用。有人以 iOS 的「藍牙瀏覽器」應用程式為例，認為這是一種良好的工程實踐。
