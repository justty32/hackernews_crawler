這篇 Hacker News 文章「This Month in Ladybird – April 2026」的留言主要圍繞 Ladybird 瀏覽器的安全性、可用性、網頁相容性、開發進度以及與其他瀏覽器的比較。

以下是留言的繁體中文總結：

1.  **安全性疑慮：**
    *   有使用者指出，目前利用 AI 工具仍相對容易在 Ladybird 中找到可利用的遠端程式碼執行 (RCE) 漏洞。
    *   儘管目前使用者基數小，攻擊者可能不感興趣，但其安全性遠不及主流瀏覽器（這些瀏覽器積極使用最新工具搜尋漏洞並支付漏洞獎勵）。因此，安全修復被認為是當務之急。

2.  **可用性與開發進度：**
    *   許多留言者表示 Ladybird 正變得「相當可用」(pretty usable)，並將其開發過程比作遊戲模擬器，透過修復特定錯誤來讓特定網站（如 CSS Doom）正常運作。
    *   不過，也有人提醒，「相當可用」與「真正可用」（足以日常使用，涉及密碼和資料的可靠性）之間仍存在巨大差距。

3.  **網頁相容性挑戰：**
    *   網頁相容性是討論的重點之一。有使用者指出，許多網站「人為地」阻擋非 Chromium 瀏覽器，以及 Widevine DRM 的難以取得，是新瀏覽器難以競爭的主要障礙（儘管 User Agent 偽裝通常能解決大部分問題，且 Widevine 主要影響 4K 串流服務）。
    *   有留言者將此與 Internet Explorer 時代的教訓相提並論，並對當前「Chrome OS 平台」的支配地位表示擔憂。

4.  **建置與發佈：**
    *   雖然目前從原始碼編譯 Ladybird 被認為相對容易，但許多使用者仍希望能有官方預編譯的二進位檔案。開發團隊已計畫在六月推出 Alpha 版本。

5.  **特定功能與討論：**
    *   功能方面，留言者討論了內建廣告阻擋（目前版本似乎已阻擋所有廣告，但有人認為外掛程式是更好的解決方案）、暗色模式（似乎已存在）和分頁管理等。
    *   一個關於 Strava 網站使用電池 API 的錯誤修復，引發了關於其用途的討論（例如用於指紋追蹤或節省電量）。
    *   此外，GTK4 / libadwaita 前端獲得了正面評價。

6.  **其他瀏覽器專案：**
    *   留言中也提到了其他新興的瀏覽器專案，例如 Dioxus Labs 開發的 Blitz（一個基於 Rust、無 JavaScript、從零開始的瀏覽器原型）以及 Servo（每月發佈二進位檔案）。

7.  **整體態度：**
